# Carnival AI Sketchbook

An interactive creative coding project celebrating Caribbean
and Black communities through Carnival-inspired visuals
that respond to bodily movement.

Inspired by Maya Man’s PoseNet Sketchbook collaboration
with Bill T. Jones and Google Creative Lab.

## Features

- Camera-based motion tracking
- Interactive, movement-driven visuals
- Carnival-inspired creative experiences

## Tech Stack

HTML, CSS, JavaScript, Bootstrap, p5.js, and PoseNet.

## Run Locally

```bash
git clone https://github.com/StacyLafume/carnival_AI_Sketchbook.git
cd carnival_AI_Sketchbook
```

Serve the folder using VS Code’s Live Server extension,
or run this command if Python 3 is installed:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080/.

No npm installation is required. Allow camera access when
prompted to use the motion-tracking experiences.

## Usage Notes

The interactive experiences require a camera and permission
to access it. Use HTTPS for the hosted site or localhost
during development.
